🚀 Space Tourism Website
This is a responsive multi-page Space Tourism website developed as part of a challenge in collaboration with Scrimba and Kevin Powell. The project demonstrates advanced web development techniques using:

🛠 React.js, React Router, Tailwind CSS, and Framer Motion 🎨✨

It focuses on efficient data handling, image optimization, and smooth animations for an immersive user experience.

🌟 Features
Dynamic Content Rendering: Integrated local data.json file to dynamically fetch and render content for destinations, crew, and technology pages.
React Router Integration: Implemented seamless navigation across multiple pages using React Router, improving user experience.
Responsive Design: Designed layouts optimized for different screen sizes, ensuring a consistent user experience across devices.
Image Optimization: Improved website performance by employing techniques such as:
Lazy Loading: Loaded images only when needed to enhance page speed.
Data Optimization: Optimized image file sizes for faster loading without sacrificing quality.
Interactive Tab Navigation: Users can easily toggle between tabs to view new information.
Smooth Animations: Added subtle animations using Framer Motion to enhance interactivity and overall design.
Hover States: All interactive elements have hover effects to provide visual feedback.

🛠️ Technologies Used
React.js: Component-based library for building user interfaces.
React Router: For navigation and routing between multiple pages.
Tailwind CSS: Utility-first CSS framework for styling and responsive design.
Framer Motion: For creating smooth and dynamic animations.
